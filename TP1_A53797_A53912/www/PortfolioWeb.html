What I created

Projects

Some projects I developed

Car Race

A 2D racing simulation developed in Python using the Pygame library. The project involved implementing an automatically driven car following a predefined track through configurable movement parameters and custom visual assets.

Ultimate Tic-Tac-Toe

Galisseia is an Ultimate Tic-Tac-Toe adventure that introduces a multi-layered board system, combining nine interconnected Tic-Tac-Toe grids into a larger strategic challenge. The game includes Pseudo-AI opponents, Campaign, Training and Friendly modes, progressive difficulty, power-ups and unlockable content. The Campaign Mode was partially inspired by the journey structure of The Odyssey.

Online Game Shop

A digital game store application inspired by platforms such as Steam. The project includes separate Client and Admin modes, allowing users to purchase games, manage libraries, write reviews and ratings, while administrators can manage products and user content.
